# GoodSheet
Health tracking app that also tracks your bodily output for a complete feedback loop to help improve your both your physical fitness and gut health

  This is a code bundle for Goodsheet. The original project is available at https://www.figma.com/design/ji90GHbeSPfUYjRCZICcsY/Goodsheet.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.
